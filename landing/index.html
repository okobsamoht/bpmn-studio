Features

Everything built in, nothing to configure

🗂️

Project Organization

Create multiple projects, each containing multiple diagrams. A clean sidebar lets you navigate your work instantly. Rename, reorder, and delete with a right-click.

🛡️

Real-time Linting

Powered by bpmnlint, the studio validates your diagram as you model. Errors and warnings appear immediately in the bottom panel with rule identifiers.

▶️

Token Simulation

Fire tokens through your process with one click. See how flow splits at gateways, which paths are taken, and validate that your model behaves as designed.

📥

Import & Export

Import existing .bpmn files from any BPMN 2.0 compliant tool. Export as standard BPMN XML or scalable SVG images for documentation.

💾

Automatic Persistence

Every keystroke and diagram change is saved automatically to your local machine. No manual save required — your work is always preserved between sessions.

🔌

Fully Offline

BPMN Studio runs entirely on your machine using Electron. No internet connection, no account, no telemetry. Your diagrams never leave your computer.

How it works

From idea to validated process in minutes

1

Create a project

Click the + button in the sidebar to create a named project. Projects are containers for related diagrams — one project per business domain, team, or workflow area.

2

Add a diagram

Right-click a project or click its add button to create a new BPMN diagram. It opens pre-populated with a start and end event, ready for your flow.

3

Model your process

Use the bpmn-js palette to drag tasks, gateways, events, and connections onto the canvas. The full BPMN 2.0 element set is available — tasks, sub-processes, lanes, pools, timers, and more.

4

Fix lint issues

The lint panel at the bottom highlights errors and warnings in real time. Each issue shows the affected element and the violated rule name so you can find and fix it fast.

5

Simulate & validate

Hit Simulate in the toolbar to enter token simulation mode. Click start events to fire tokens and watch them traverse your flow, revealing dead-ends or unreachable branches.

6

Export & share

Export your diagram as standard BPMN 2.0 XML to share with other tools (Camunda, Activiti, Flowable) or as SVG for embedding in documentation or presentations.
